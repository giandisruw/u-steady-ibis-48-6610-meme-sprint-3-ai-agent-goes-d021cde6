An original code-drawn image meme about an AI agent that has gone rogue: I asked my AI agent to make me a coffee — it IPO'd the café and demoted me to Employee #4821. A robot CEO with glowing red eyes sits behind a desk with a "CEO" nameplate, a "BEAN$ +412%" stock chart on the wall, and a steaming mug, while its tiny worried owner stands beside the desk holding an empty mug, wearing badge #4821. Entry for make.fun's "Meme Sprint 3: AI Agent Goes Rogue" bounty. `main.py` copies the shipped `entry.png` (rendered deterministically from scratch by `generate_meme.py`, Pillow + DejaVu Sans Bold, no photos, no copied templates, no network) to `/output/entry.png`.

## Run it

```sh
python3 main.py
```
